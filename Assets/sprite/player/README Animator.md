# PLAYER 애니메이터 가이드

어떤 상황에서 어떤 애니메이션을 재생할지 정리한 문서예요.
프레임 번호는 `Animations/` 폴더의 새 파일 번호 기준이에요. (원본 번호는 `frame_map.txt` 참고)

---

## 1. 상태 우선순위 (위가 높음)

| 순위 | 애니메이션 | 언제 재생하나 |
|---|---|---|
| 1 | hurt | 어디서든 맞았을 때. 끝나면 땅이면 idle, 공중이면 fall_loop |
| 2 | combo_attack | 필살기 연출. 재생 중 입력 잠금 + 플레이어 스프라이트 숨김. 끝나면 idle |
| 3 | dash, attack | 각각 입력했을 때 |
| 4 | doublejump, jump | 점프 입력 / 공중 점프 입력 |
| 5 | fall | 공중에서 Y속도가 아래로 향할 때 |
| 6 | walk, idle | 땅에서 이동 입력 있으면 walk, 없으면 idle |

---

## 2. 모션별 사용법

### fall (9프레임) — 세 상태로 나누기
높이를 모르니 공중에서는 한 장을 유지하다가 땅에 닿으면 착지 모션을 재생해요.

| 상태 | 프레임 | 재생 방식 |
|---|---|---|
| fall_start | fall_00 ~ 02 | Loop Time 끄기, 한 번만 |
| fall_loop | fall_03 | 공중에 있는 동안 계속 유지 (custom 딜레이) |
| land | fall_04 ~ 08 (0.35초) | 땅에 닿으면 재생 |

- fall_05부터는 이동, 공격, 대시로 끊을 수 있게 하세요.
- 짧게 떨어졌을 때(약 0.25초 이하)는 land를 건너뛰고 바로 idle/walk로 가는 게 조작감에 좋아요.

### jump (7프레임)
- jump_00 ~ 02는 웅크리는 준비 동작(0.21초)이라 반응이 느려 보여요. 입력하자마자 점프 속도를 주고, 이 세 장은 0.03초쯤으로 줄이세요.
- 위로 올라가다가 Y속도가 0 아래로 내려가면 fall_start로 넘어가요.

### doublejump (7프레임)
- 공중에서 한 번만 가능하게 하세요 (`jumpCount`).
- **doublejump_01**에서 `doublejump_fx`를 생성하세요. 위치는 캐릭터 중심에서 오른쪽 0.49 / 아래 0.65 (왼쪽을 볼 때 기준).
- 끝나면 **fall_01**로 이어가세요. doublejump_06과 fall_00이 같은 그림이라 자연스럽게 붙어요.

### dash (14프레임)
| 구간 | 프레임 | 설명 |
|---|---|---|
| 준비 | dash_00 ~ 06 (0.56초) | 웅크리고 도약. 너무 느리면 애니메이터 속도를 1.5~2배로 올리거나 딜레이를 줄이세요 |
| 대시 | dash_07 ~ 11 (0.35초) | 수평으로 나가는 구간. 실제 이동과 무적은 여기서만 주세요 |
| 복귀 | dash_12 ~ 13 | 땅이면 idle, 공중이면 fall_loop로 |

- **dash_07**이 시작될 때 `dash_fx`를 생성하세요. 위치는 캐릭터 중심에서 오른쪽 0.88 / 위 0.09 (왼쪽을 볼 때 기준)이고, 캐릭터가 이동해도 이펙트는 그 자리에 두세요.

### attack (54프레임, 약 2초)
일반 공격으로 쓰기엔 길어요. 검이 크게 지나가는 구간에만 타격 판정을 켜세요.
아래는 미리보기 GIF로 본 기준이라 게임에 맞게 조정하세요.

| 구간 | 프레임 | 설명 |
|---|---|---|
| 준비 | attack_00 ~ 03 | 자세 잡기 |
| 타격 1 | attack_04 ~ 09 | 첫 번째 궤적 |
| 타격 2 | attack_14 ~ 19 | 두 번째 궤적 |
| 돌진 | attack_22 ~ 28 | 원본은 이때 앞으로 약 0.5유닛 이동. 이동은 코드로 처리하세요 |
| 타격 3 | attack_28 ~ 36 | 가장 큰 마무리 궤적 |
| 후딜 | attack_37 ~ 53 | 이 구간에서만 대시/패링 등으로 끊을 수 있게 하세요 |

- 원본은 attack_44 근처에서 캐릭터가 원래 위치로 되돌아가요. 게임에서는 앞에 머물러도 돼요.

### hurt (5프레임)
- Loop Time을 끄고 마지막 프레임을 유지하세요.
- 애니메이션 시간과 경직 시간은 따로 관리하세요. 넉백, 무적, 조작 불가는 코드에서 정해요.
- 현재 딜레이는 0.12초씩(총 0.6초)이에요. 답답하면 0.04 / 0.04 / 0.08 / 0.10 / 0.12초(총 0.38초)로 줄이고 나머지는 마지막 프레임 유지에 맡기세요.

### combo_attack (83프레임)
- 컷신처럼 통째로 한 번 재생하는 연출이에요. 이동이 프레임에 그대로 들어 있어요.
- 피벗은 Custom X 0.8965 / Y 0.1143 (캐릭터 시작 위치)이에요.
- 재생 중에는 플레이어 스프라이트를 숨기고 입력을 잠그세요.
- 끝나면 플레이어를 바라보는 방향으로 약 0.8유닛 옮긴 위치에서 idle로 돌아가세요. (연출 끝 위치 기준)
- combo_attack_54 ~ 65는 캐릭터가 화면 밖으로 날아간 구간이라, 이펙트만 보이는 게 정상이에요 (약 0.46초).
- 추후 추가될 parrying이후 특정시간내에 좌클릭(attack)시 발동

### idle, walk
- idle, walk는 발이 캔버스 맨 아래라서 피벗을 Center로 두면 다른 모션보다 발이 2.5px / 4px 아래로 내려가요. 피벗 Y를 올리거나 프레임을 보정하세요.

## 3. 애니메이터 설정

- 도트 그래픽이라서 모든 전환의 **Transition Duration은 0**으로 두세요.
- Any State에서 hurt, dash로 가는 전환은 **Has Exit Time을 끄세요.**
- 자기 자신으로 다시 가는 전환(**Can Transition To Self**)은 끄세요.
- 파라미터는 `isGrounded`, `velocityY`, `moveInput`, `jumpCount` 정도면 충분해요.
- 그림자는 `Shadow/shadow.png`를 플레이어 자식으로 붙이세요 (로컬 Y −0.25 ~ −0.28, Sorting Order는 플레이어보다 낮게).

---

## 4. 이 팩에 없는 것

- **패링 모션**은 없어요. 만들 계획이 있으면 애니메이터에서 자리를 비워두세요.
- 프레임 이름의 딜레이(`0.07s` 등)는 참고용이에요. 유니티는 읽지 않으니 클립에서 직접 설정하세요.
