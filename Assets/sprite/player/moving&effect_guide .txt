8. hurt (5프레임, 각 0.12초)
============================================================
원본은 첫 프레임(hurt_00) → 두 번째(hurt_01) 사이에 캐릭터가 뒤로 0.38유닛 밀려나요.
추천: 맞은 방향의 반대쪽으로 넉백 0.4유닛을 0.1초에 걸쳐 주세요. 경직, 무적, 조작 불가 시간은 코드에서 따로 정하세요.
애니메이션은 Loop Time 을 끄고 마지막 프레임을 유지하세요.

============================================================
구현 방법 (모든 모션 공통)
============================================================
방법 A) 애니메이션 클립에 플레이어 루트의 Position 커브를 넣기
  - 표의 t 와 x(또는 dx)를 그대로 키프레임으로 입력하세요. 커브는 Linear 로 하면 원본 느낌이 나요.
  - 왼쪽을 볼 때 기준이니, 오른쪽을 볼 때는 값에 -1 을 곱하세요.
방법 B) 코드로 속도를 주기
  - 구간 속도 = (구간 이동량) / (구간 시간). 예: 패링 첫 구간은 0.34유닛 / 0.04초 = 8.5유닛/초.
  - 이동 중에 벽이나 적에 막히면 이동을 멈추게 하세요 (스프라이트가 스스로 움직이지 않으니까 충돌 처리가 쉬워요).
점프, 낙하, 2단 점프의 좌우 이동은 원본에서 계속 약 2.3~2.8유닛/초로 왼쪽으로 움직였어요.
이건 애니메이션 이동이 아니라 '공중 이동 입력 속도'로 처리하세요.

공통 규칙
- 이펙트는 플레이어의 자식으로 붙이지 말고 '월드에 따로 생성'하세요. (플레이어가 움직여도 그 자리에 남아요)
- 재생이 끝나면 삭제하세요 (Destroy).
- 위치는 캐릭터가 왼쪽을 볼 때 기준이에요. 오른쪽을 보면 x 부호와 스케일 x 를 반대로 하세요.
- '뒤쪽' = 바라보는 방향의 반대쪽이에요 (왼쪽을 볼 때 오른쪽).
- 이펙트 이미지 피벗은 Center 로 두고, 아래 위치에 이미지 정중앙이 오게 하세요.
- 바닥(발 높이)은 플레이어 피벗보다 0.25유닛 아래예요.
